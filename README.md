# لوحة لجنة المرافق والتجهيزات — جامعة تبوك

## النشر عبر GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع ملف `index.html` إلى جذر المستودع.
3. افتح Settings → Pages ثم اختر Deploy from a branch و main و /(root).
4. افتح الرابط الذي توفره GitHub Pages بعد النشر.

كلمة الدخول التجريبية: `123456`. تنبيه: كلمة المرور داخل HTML ليست حماية أمنية، ويمكن كشفها عند عرض المصدر؛ استخدم استضافة بمصادقة حقيقية للمعلومات الحساسة.
